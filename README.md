# BRP HUB

Project Berpa hub with one Junkie key loader and game-specific modules.

Supported games:

- Blade Ball (protected Junkie script)
- Storage Hunters: Open World (`UniverseId 10261267004`)

Loader:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Ericberpa/Berpa-code/main/keyCheck.lua"))()
```

The Storage Hunters module includes bounded Auto Bid, Auto Join, Auto Loot,
Auto Sell (favorites are preserved), Item ESP, instant prompts and useful
teleports.
